# Meu Portfólio

Este é meu portfólio pessoal desenvolvido durante meus estudos em Análise e Desenvolvimento de Sistemas.

O objetivo deste projeto é reunir meus trabalhos, acompanhar minha evolução e apresentar minhas habilidades em desenvolvimento web.

## Tecnologias utilizadas

* HTML5
* CSS3

## Objetivo do projeto

Praticar desenvolvimento web na prática, melhorar minha base em HTML e CSS e construir um espaço para apresentar meus projetos e minha evolução como desenvolvedora.

## Aprendizados

* Estruturação com HTML
* Estilização com CSS
* Organização visual de páginas
* Responsividade básica

## Próximos passos

* Adicionar novos projetos
* Melhorar o design
* Incluir interatividade com JavaScript
